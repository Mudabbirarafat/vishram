# Canoply Clone (Next.js + Tailwind)

This is a deploy-ready clone starter of the Canoply template (hero, features, CTA, header, footer).
Built with:
- Next.js (app router)
- Tailwind CSS
- framer-motion

How to run:
1. `npm install`
2. `npm run dev`
3. Open http://localhost:3000

Notes:
- This is a pixel-focused starter. Replace assets in `/public` with higher-fidelity screenshots or SVGs for closer parity.
- Deploy to Vercel for a quick live demo.

# Canoply Clone (Next.js + Tailwind)

[![CI](https://github.com/Mudabbirarafat/canoply-clone/actions/workflows/ci.yml/badge.svg)](https://github.com/Mudabbirarafat/canoply-clone/actions/workflows/ci.yml)

A pixel-perfect, deploy-ready clone of the Canoply template, built with modern technologies.
Includes a responsive homepage with Hero, Features, CTA, Header, Footer, and additional sections like FAQ, Blog, Location, and Reviews.

# Built with:

Next.js 15 (App Router)

Tailwind CSS (utility-first styling)

Framer Motion (smooth animations)

Responsive design (mobile, tablet, desktop)

# 🌐 Live Demo

https://canoply-clone.vercel.app/

# 📦 Components & Sections

Header – Navigation menu, logo, responsive layout

Hero – Main headline, call-to-action buttons, illustrations

Features – Highlight key features with cards

CTA – Call-to-action section for engagement

FAQ – Frequently Asked Questions

Blog – Section showcasing latest blog posts or articles

Location – Map or contact location section

Reviews – Testimonials or customer reviews

Footer – Links, social media, and copyright

# ⚡ How to Run Locally

Clone the repository:

git clone https://github.com/Mudabbirarafat/canoply-clone.git
cd canoply-clone


Install dependencies:

npm install


Start the development server:

npm run dev


Open your browser:

http://localhost:3000

# 📝 Features & Highlights

Fully responsive and mobile-first design

Clean Next.js App Router structure with /app and /components

Reusable components for easy customization

Framer Motion animations for smooth transitions

Easily deployable on Vercel for a live demo

Supports customization of assets in /public (SVGs, images, icons)

# 🚀 Deployment

Deployed on Vercel: https://canoply-clone.vercel.app/

Automatic deployment on push to GitHub

Build command: npm run build

Output directory: .next
